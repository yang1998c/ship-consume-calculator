# 船舶能耗计算器 1.0.4 —— 版本说明（AGC 上传用）

## 版本信息

- 版本号：1.0.4（versionCode 1000004）
- 包名：com.kokoro.shipenergy
- 支持设备：手机
- 最低系统：HarmonyOS 6.1.1(24)

## 更新内容（可直接粘贴到应用市场）

1. 首次启动引导
   - 同意隐私说明后，界面变暗并用箭头指向「使用方法」按钮
   - 仅首次出现，看过不再打扰

2. 界面全面对齐 HarmonyOS 设计规范
   - 系统色板、沉浸式半透明头部、悬浮胶囊页签
   - 图标改用系统 Symbol 矢量图标
   - 支持浅色 / 深色两套主题

3. Excel 导入导出
   - 导出四表报表：时间区间明细 / 航次统计 / 时间汇总 / 油耗参数
   - 支持从同结构 Excel 导入，一并恢复航次信息与油耗参数
   - 提供空白模板，最后一页附「填写说明」

4. 数据校对
   - 航次页新增营运时间交叉校验：抵港时间差与录入区间合计不符时红字提示

5. 其他
   - 页签切换改为水平推移动画
   - 时间精度统一到分钟
   - 新增「使用方法」说明（八节，含录入、航次、正午、Excel 等）

## 隐私说明

- 应用无联网权限，不采集、不上传任何数据
- 全部计算与存储在本机完成
- 仅在用户主动导出 / 导入时使用系统文件选择器

## 已知限制

- 跨时区记录导出时按各端船钟时间写出，表格不含时区列，
  再导入时按本机时区解释
