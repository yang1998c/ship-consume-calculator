# 船舶能耗计算器 1.0.3 —— 版本说明（AGC 上传用）

## 版本信息

- 版本号：1.0.3（versionCode 1000003）
- 包名：com.kokoro.shipenergy
- 支持设备：手机
- 最低系统：HarmonyOS 6.1.1(24)

## 更新内容（可直接粘贴到应用市场）

本次更新重点在界面与数据交换：

1. 界面全面对齐 HarmonyOS 设计规范
   - 采用系统色板、沉浸式半透明头部、悬浮胶囊页签
   - 图标改用系统 Symbol 矢量图标
   - 支持浅色 / 深色两套主题

2. 新增 Excel 导入导出
   - 导出为四表结构报表：时间区间明细 / 航次统计 / 时间汇总 / 油耗参数
   - 支持从同结构 Excel 导入，一并恢复航次信息与油耗参数
   - 提供空白模板下载，模板最后一页附「填写说明」

3. 新增页签切换过渡动画（水平推移）

4. 时间精度统一到分钟，去掉秒

## 隐私说明

- 应用无联网权限，不采集、不上传任何数据
- 全部计算与存储在本机完成
- 仅在用户主动导出时使用系统文件选择器

## 已知限制

- 跨时区记录导出时按各端船钟时间写出，表格不含时区列，
  再导入时按本机时区解释（如需无损往返，可在表格右侧自行补充
  「开始时区 / 结束时区」两列，导入端已支持）
